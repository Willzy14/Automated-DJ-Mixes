- **One vote and shared samples.** Any nearby rebuildable track can place the boundary, including a continuing track with no cut there. A single vote suffices. I reproduced a quiet cut at **+30 ms** getting a **-29.99 ms** locate when the audible track played a phase-shifted copy of the same sample. If the rendered timing error varies across that span, a dominant transient can determine the lag several milliseconds away from the cut. For a missing WAV, the code tries the ALS-relative path first and the recorded path second. With neither available, the clip supplies no vote. ### 6. Performance and file safety

Source files are opened with `"r"`, cached as handles, and closed in `finally`. With ordinary warp markers, each boundary reads only the source span corresponding to its two-second template. Two hundred boundaries with seven-minute sources do not normally put those full WAVs in memory. A pathological warp segment can still make `pos.min()` to `pos.max()` span a whole file or extend far past it. `_read_mono_padded` allocates that requested span before clamping the file read. Bound the allocation to a plausible source span and reject invalid marker geometry (`render_check.py:1480`).
