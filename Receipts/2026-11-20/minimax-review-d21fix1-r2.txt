Is this a realistic false alarm here? `apply_model` is an unusual name for a non-Demucs API; it is Demucs-specific vocabulary. **The narrower and more likely false alarm: shadowing.** `func_names` is collected per-file from `from demucs.apply import apply_model`. If a file both imports Demucs' `apply_model` and separately defines or receives a *different* callable with that name, every reference to the local one is treated as the Demucs function. The test file's `"unrelated name"` good-case only exercises a file with **no** Demucs import (`func_names` empty), so it does not cover the shadowing case at all. A file that does `from demucs.apply import apply_model` and also has `def apply_model(x): ...` (a local convenience wrapper of the same name) would have all its local calls flagged as "call without literal shifts=0". The `getattr` branch does not consult `func_names` or check whether the module imports Demucs. This is a strict superset of the attribute problem and is the same shape of false alarm, one call spelling wider.

**A third: the per-module tests pin the call count.** `test_probe_stem_kick_grid_separation_passes_shifts_zero`, `test_kick_model_adapter_separation_passes_shifts_zero` and `test_stem_section_probe_separation_passes_shifts_zero` all assert `len(calls) == 1`. `_apply_model_calls` matches on `fn.id`/`fn.attr == "apply_model"`. The intent (pin the call) is defensible, but the failure message will be an opaque `assert 2 == 1` rather than "this call is missing shifts=0", and it blocks a correct change.

**Net assessment on false alarms:** the guard is repo-wide and its attribute/getattr matching is spelling-only with no Demucs-import scoping. In the current tree the risk is low, since `apply_model` is Demucs-specific vocabulary and I confirmed `stem_grid.py` (the one file I could read in full) contains no `apply_model` identifier. But the mechanism will produce a false alarm the first time any non-Demucs code in `Source/` or `Tools/` uses an `apply_model` attribute, or any file shadows the imported name, and the blast radius is the entire suite.
